# رصدگیر — سامانه رصد اخبار

این پروژه یک سایت فارسی راست‌چین است که خبرها را از خوراک‌های خبری قابل‌دسترسی جمع می‌کند و هر ۱۵ دقیقه با GitHub Actions فایل داده‌های خبر را به‌روزرسانی می‌کند. زمان و تاریخ نمایشی سایت همیشه بر اساس منطقه زمانی `Asia/Tehran` محاسبه می‌شود؛ زمان‌بندی ۲۰:۳۰ UTC معادل ۰۰:۰۰ روز بعد در تهران است.

## راه‌اندازی

1. این پوشه را در یک مخزن GitHub بارگذاری کنید.
2. در تنظیمات مخزن، **Settings → Actions → General → Workflow permissions** را روی **Read and write permissions** قرار دهید تا Workflow بتواند `docs/news.json` را commit کند.
3. در بخش **Actions**، Workflow با نام **Update Rasadgir news** را باز و یک بار دستی اجرا کنید.
4. برای انتشار سایت با GitHub Pages، از **Settings → Pages** گزینه انتشار از شاخه `main` و پوشه `/docs` را انتخاب کنید. توجه: فایل `index.html` باید در پوشه `docs` هم باشد یا تنظیم انتشار روی ریشه مخزن انجام شود. ساده‌ترین راه: `index.html` را به `docs/index.html` کپی کنید و آن نسخه را نگه دارید.

## منابع خبری و اتصال APIها

به‌صورت پیش‌فرض، اسکریپت از Google News RSS برای جست‌وجوهای مرتبط با Reuters، Fox News، خبرهای سیاسی، نظامی، اقتصادی، گزارش‌های عمومی و تحلیل‌ها استفاده می‌کند. این روش به معنی دسترسی مستقیم یا تضمین پوشش همه مطالب آن رسانه‌ها نیست؛ نتایج تابع فهرست‌بندی و دسترسی RSS است.

برای خوراک‌های RSS اضافی، در **Settings → Secrets and variables → Actions → Variables** متغیر `EXTRA_RSS_URLS` را بسازید و هر URL را در یک خط قرار دهید.

### X / Twitter
- Secret به نام `X_BEARER_TOKEN` بسازید و توکن رسمی API را قرار دهید.
- دسترسی جست‌وجوی اخیر و سهمیه API به طرح حساب X بستگی دارد.
- برای تغییر عبارت جست‌وجو، Variable به نام `X_SEARCH_QUERY` بسازید.

### Instagram
- Secretهای `INSTAGRAM_ACCESS_TOKEN` و `INSTAGRAM_USER_ID` را اضافه کنید.
- این اتصال فقط رسانه‌های حساب حرفه‌ای مجاز و متصل به Instagram Graph API را می‌خواند؛ جست‌وجوی آزادانه تمام حساب‌ها و استوری‌ها را انجام نمی‌دهد.

### Telegram
- Secret به نام `TELEGRAM_BOT_TOKEN` را اضافه کنید و بات را به کانال/گروه مربوطه اضافه کنید؛ برای کانال معمولاً دسترسی ادمین لازم است.
- Bot API تاریخچه کامل کانال را به شکل عمومی ارائه نمی‌کند؛ این اتصال فقط پیام‌هایی را می‌بیند که از طریق `getUpdates` در دسترس بات باشند. برای منابع عمومی، از RSS رسمی یا سرویس واسطی استفاده کنید که مجوز لازم را دارد و URL آن را در `EXTRA_RSS_URLS` قرار دهید.

## نکات مهم

- اجرای زمان‌بندی‌شده GitHub Actions ممکن است با تأخیر انجام شود؛ تضمین دقیق ثانیه‌ای برای نیمه‌شب ندارد.
- کد فعلی خبرها را گردآوری و تکراری‌ها را تا حد تیتر حذف می‌کند؛ صحت‌سنجی مستقل، ترجمه حرفه‌ای، تشخیص خبر جعلی و خلاصه‌سازی هوش مصنوعی در این نسخه پیاده‌سازی نشده است.
- برای امنیت، کلیدهای API را داخل HTML یا کد عمومی قرار ندهید؛ فقط از GitHub Secrets استفاده کنید.
- برای استفاده از GitHub Pages، `docs/index.html` را بسازید/به‌روز نگه دارید. Workflow فقط `docs/news.json` را تولید می‌کند.
